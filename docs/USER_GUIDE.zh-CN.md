# 择影使用指南

一款仅在 iPhone 本机保存清理进度的照片整理 App。左划或点“待删除”暂存删除决定；右划或点“保留”保留；“待决定”单独存放。照片侧边点按默认关闭，可在设置开启。默认情况下，收藏和删除都在清单页分别确认后才写入系统照片图库。

## 为你建议

- 底部“为你建议 / Suggestions”标签使用魔法棒图标；首页同名彩色胶囊会直接切换到这个标签。旁边的“随机清理 / Shuffle Review”胶囊用于打乱未处理照片。
- 建议页按相似照片、临时截图、重复副本排列；分类胶囊参考系统邮件：当前分类展开显示图标与名称，其他分类显示图标，空分类仍可进入查看筛选依据。左上角随机按钮可以打乱当前建议顺序。支持暂停和继续分析、更新建议，以及恢复跳过的建议。分析仅读取本机可用资源，不主动下载 iCloud 原片。
- 只有完整照片资源内容一致时才标为“重复副本”。画面相近但内容不同的原图与修图版作为“相近版本”展示，支持同时保留。相似组没有两张上限；同一拍摄时段、画面足够接近的多张照片会一起比较，变化明显的照片仍分开以避免误判。进入相似组时会优先为这一组计算 Vision 美学评分，不等整库检查结束；组内小图优先显示本地清晰版本，准备时可先显示缩略图。全部成员均有评分且存在分差时，标出一张建议保留的照片，并在它下方显示分数与分差。分数接近时才参考像素尺寸；评分不可用或缺乏可靠优势时会结束比较提示，也不强行推荐。已收藏或保留的照片优先受到保护。建议不会自动替用户选择；可逐张打开高清大图，在大图底部查看依据、选择保留及本机可获得的文件大小。到达组内最后一张时可点“下一组”，将本组未保留的照片加入待删清单，并直接打开下一组的第一张大图；下一组为截图时转入逐张截图审核。Live Photo 不凭静态预览确认重复。
- 比较页先选择要保留的照片，再把其余项目加入待删清单；确认后自动进入下一组，无需返回列表。已收藏、明确保留或存在收藏与相簿待办的照片受到保留保护；整组决定可以一次撤销，同一会话可按顺序撤回比较组。点照片可分页放大查看和查看信息。
- 截图只推荐超过 90 天且识别到临时内容的项目，按订单结果、取件码、验证码、已送达物流、过期活动与优惠券分类；不会收录所有旧截图，也不按固定数量拆组。分类规则更新后，旧的截图识别缓存会在下一次扫描时重新检查，已有结果在复查期间继续显示。进入分类后沿用逐张滑动审核，离开后可继续未处理部分，完成分类后仍可撤销最后一张。未识别到内容或没有本地预览的截图仍可按月份审核。建议不会自动删除。
- 图库加载完成后，使用 App 时即开始检查照片，打开建议页也会检查。旧截图会优先分析；检查中仅显示“正在检查你的照片”，不展示扫描数量或进度条。离开 App 时，当前分析先在系统允许的短暂后台时间内继续；之后由 iOS 自行安排后台处理，充电也不保证立即运行。后台处理无需接电源，但低电量或明显发热时暂停并延长重试间隔；分析按批次保存缓存、接续处理，不主动下载 iCloud 原片。若系统未接受后台任务，建议页会显示提示；手动暂停也会暂停后续后台检查。
- “跳过本组”不计为照片已审核。连续审核会保留尚未完成的照片组，重新进入建议页可以继续。

## 开发与运行

1. 用 Xcode 打开 `Zeying.xcodeproj`。
2. 选择 `Zeying` scheme 与 iPhone 模拟器或设备。安装到个人设备时，在 Signing & Capabilities 中选择自己的开发团队，并按需修改 Bundle Identifier。
3. 运行后允许照片访问。选择“限定访问”时，App 只会显示获准访问的项目，可在 App 内通过系统选择器增加照片。

最低系统版本为 iOS 26。当前工程已用 Xcode 26.6 完成模拟器与连接的 iPhone 17 Pro Max 设备构建；iOS 27 的实际交互仍需在设备上运行检查。

## 使用说明

- 清理决定、待收藏和待删列表保存在设备上的 SwiftData 数据库中；卸载 App 会移除这些本地进度。
- 首次读取获准访问的图库时显示全屏渐变开屏画面；读取完成后自动进入首页。尚未授权时会直接显示权限入口。
- 首次授权入口和使用指南第一页均说明：本地清晰照片会提前准备；仅存于 iCloud 的照片默认不自动下载原片。可跳过的指南还说明左右滑动、待决定和清单确认；之后可从“设置”再次查看完整指南。
- 标准字号下，审核页的删除、撤销、稍后、收藏、保留按钮位于同一排；辅助功能大字体下改为可滚动的文字按钮，纵向滚动优先于卡片决策手势。卡片上方左侧是带灰色“相簿”入口和独立加号的横向相簿胶囊，末端内容裁切在圆角边界内；右侧只显示文件大小，照片信息在右上角。按月份审核时，顶部标题显示当前照片的完整拍摄日期。审核中的照片以叠放卡片呈现，横向照片按自身比例显示，不填充高大的留白卡片；划动时下一张随手势显露，删除和保留提示逐渐变清晰。标准字号下照片和视频卡片可左右划动，横向照片上下及左右的空白区域也能起手滑动；视频底部的原生播放控制区保留给播放操作。开启侧边点按后，照片和周围空白审核区域左半边点按待删、右半边点按保留，较靠上的空白也能快速分类；按钮按下和成功操作会提供视觉反馈。系统照片里已收藏的照片显示“已收藏”，尚未提交的收藏显示“待确认收藏”。照片仍可双指放大查看。
- 审核页进入本地视频后会自动静音播放；只有本地没有可播放版本时才显示“播放视频”，由用户决定是否载入可能位于 iCloud 的内容。每次进入审核页时默认静音。点按视频上的扬声器按钮开启声音后，本次审核的后续视频也保持有声，直到再次点按静音或退出审核页。可用设备音量按钮调整音量。清单中的视频仍需主动点按播放。
- 审核页返回键旁的随机按钮只打乱当前月份、类型或相簿里尚未处理的照片和视频；已处理部分与撤销记录保持原位。随机不会切换当前卡片；重开后保留本组随机顺序和当前位置。
- 实况照片从预览开始就在右上角显示实况标识；长按 0.9 秒才开始载入动态内容，轻点切换不显示载入转圈。松手停止播放，但已开始的载入会继续完成并留在当前卡片，方便再次长按立即播放。中央轻点不会作决定。照片双指放大后可拖动画面。
- “继续清理”会回到上次使用的月份、类别、相簿或随机清理入口，从其中尚未处理的照片接着开始，月份按年月保存，跨时区后不会因月初时间偏移进入上个月。未有历史记录时显示“开始整理”；全部处理完后隐藏。首页“随机清理”可打乱所有未处理照片的顺序。待决定照片会以与“继续清理”和清单待办相同样式的首页卡片显示，点按可重新选择。
- 首页统计行显示当前可访问及已决定数量；“待决定”不计为已决定。月份全部浏览但仍有待决定时显示“已浏览”和待决定数量；月份默认显示最近 6 个，使用更紧凑的非玻璃条目；个人相簿默认显示前 8 个，其他内容可展开。“类型”显示有内容的照片、视频等入口和 PhotoKit 返回的媒体智能相簿类型。
- 首页“择影已清理”沿用玻璃卡片，紧接顶部统计胶囊，展示已清理照片、Live 转静态和已知资源大小；边缘使用与“随机清理”一致的静态蓝紫渐变，按下时短暂发光，点按可打开包含视频数量的完整清理统计。
- 审核页右上角的系统分享按钮可分享当前照片或视频；准备 iCloud 原片时可能需要等待下载。照片仍可直接双指放大。
- 实况照片审核页右上角有“转为静态照片”：先用 PhotoKit 导出当前显示的静态画面，复制原拍摄时间与可写个人相簿，并自动核对副本。创建、待核对、核对通过与核对失败分别显示，已有副本不等于通过核对。副本通过核对后才显示删除原件的系统确认；准备过程可以取消。转换中断会自动尝试恢复，失败会保留原件。此操作需要完整照片访问权限，iCloud 原片可能先下载。静态副本不会继承动态片段或照片的编辑历史。
- 审核页灰色“相簿”入口可打开全部相簿搜索，旁边的加号用于新建相簿；其后可左右滑动快捷选择个人相簿。已加入的相簿会排在前面并显示勾号；点按勾号并确认后，只会从该相簿移除照片。其余相簿按常用程度排序，点选会视为保留，并先保存在本机；待加入状态显示时钟，清单中“待整理相簿”需再次确认才写入系统照片。每张照片暂存一个目标相簿，重新选择会替换先前目标。有限权限下只能整理获准访问的照片。
- 新建相簿分为系统创建和加入照片两步；如果 App 恰好在两步之间退出，清单会保留待办，并在检测到新出现的同名相簿时提示手动选择它，避免自动创建重复相簿。
- 底部“设置”可控制触觉反馈、侧边点按、收藏保护和“自动下载 iCloud 原片”，也可查看照片权限、清理统计和版本。收藏保护默认开启，已收藏或待收藏的照片加入待删前会再次确认。iCloud 自动下载默认关闭，选择在重启后保留；开启后，审核中的照片、清单大图和建议大图当前页允许从 iCloud 下载高清内容，可能消耗流量和设备空间，不会批量下载整个图库。
- 左划或点删除会把照片列入待删清单；在清单确认后，照片才会提交到系统图库，iOS 还会显示系统删除确认。一次批量提交可减少系统弹窗。删除会作用于整个图库，而非仅从当前相簿移除；iCloud 照片的删除也可能同步到其他设备。
- 未收藏照片的星标按钮先把照片视为保留并列入待收藏；清单页单独确认后才同步系统收藏。已经收藏的照片显示实心星标，点按“取消收藏”并确认后会移除系统收藏标记，照片仍留在图库。
- 有本次操作记录时，“撤销”会同时恢复此前决定和相簿待办；重开后的“上一张”用于回看并展示上次决定。
- 清单中的待删项目可点开大图预览：本地照片直接显示清晰版本，双指缩放和拖动查看，不显示缩放按钮或说明；仅存于 iCloud 的原片仍遵循设置中的自动下载开关。视频可以主动播放；“改为保留”是独立按钮，“全部改为保留”取消整批待删决定。
- 最终清单显示待收藏、待删除、待整理相簿、未完成的静态转换及相关不可访问记录，不列出已保留照片；首页有待办时会提示前往清单查看并确认。
- 清单的待收藏、待删除标题右侧分别提供原生蓝色“收藏”和“删除”按钮，点按后仍会弹出各自的确认对话框。
- 审核页会提前准备后续 8 张照片的本地清晰预览，并在首张和下一张准备好后展示队列。本地照片优先显示清晰版本；仅存于 iCloud 时先尝试本地缩略图，必要时为当前照片向 PhotoKit 请求低清小图，这可能使用网络。开启“自动下载 iCloud 原片”后，当前照片的小图会进一步升级为高清内容；不会预下载后续云端照片。列表缩略图和建议分析仍只读取本机资源。退出审核时停止预取。无论开关状态，主动播放、分享、转换或确认获取云端大小时都可能加载对应内容。
- 本地照片会在预览时自动读取文件大小，读取过程不会下载 iCloud 原片；iCloud 原片或大视频大小未知时，可主动点按获取，这可能下载原片并消耗流量。
- 首页累计显示经择影确认删除的照片与视频数量，以及删除前已知的资源大小。该字节数不等于马上释放的设备空间；系统“最近删除”和 iCloud 同步仍会影响实际可用空间。
- 已读取的文件大小按照片修改时间缓存；视频预览和文件大小获取彼此独立。
- 若照片被外部删除、拒绝访问或暂时超出限定访问范围，清单和待决定页会保留并显示不可访问记录，可前往系统设置或管理获准照片；完整权限下可明确确认，只清理这些本地记录。
- 首版不包含系统“人物与宠物”分类。公开 PhotoKit API 没有提供读取该分组的接口。

## 命令行构建

若 `xcode-select` 指向 Command Line Tools，可在命令前指定 Xcode：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project Zeying.xcodeproj -scheme Zeying \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/ZeyingDerived CODE_SIGNING_ALLOWED=NO build
```

自动测试在 Xcode scheme 的 Test 动作中运行。PhotoKit 授权、iCloud 下载、系统收藏、相簿写入、实况照片转换与系统删除确认仍需在设备或可用的 iOS 模拟器上手动验收。
